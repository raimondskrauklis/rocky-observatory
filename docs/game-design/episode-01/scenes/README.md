# Episode 1 Scenes

Scene-by-scene breakdown of Episode 1: The Lost Observatory. Crafted by the creative producer using the `craft-scene` skill workflow. Each scene follows the template in `.cursor/skills/craft-scene/SKILL.md`.

Scene 0 decided: the telescope is the RT-32 dish, not a dome. The restoration chain in the GDD (power → dome → optical telescope → receiver) is superseded by power → dish drive → receiver → antenna and is re-crafted scene by scene; the GDD is updated as each scene is accepted.

**Crafting paused after Scene 2 (director, 2026-09-21).** Scenes 0–2 are enough for the grey-box slice (`roadmap.md`, Phase 2). Scenes 3–5 are crafted after the slice has taught us what a Pluto form and a puzzle actually cost. Seeds already planted for them: the star chart's circled point, the dead tape recorder, "how does it look without an eye?", the pocketed notes.
